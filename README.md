# 訪問介護 研修アプリ

令和8年度の年間研修計画（12か月分）の研修資料・確認テストを使って、職員の研修受講と記録をまとめて行うWebアプリです。
運営指導（実地指導）で確認される研修記録・委員会・訓練の記録を、そのまま印刷・PDF保存できます。

## 使い方

1. `index.html` をブラウザ（Chrome・Edge・Safari）で開きます。インストールは不要です。
2. 「設定・バックアップ」で事業所名・年度・管理者などを入力します。
3. 「職員」で職員を登録します（入職日を入れると、研修の対象者が自動で判定されます）。
4. 研修の日に「研修資料・テスト」で資料を表示し、終わったら各職員が確認テスト（10問）を受けます。
5. 「研修実施記録」で実施日・時間・講師・出欠などを記入します（様式1・様式2）。
6. 欠席者は資料を読んで確認テストを「研修を欠席した」で受験すると、回覧確認表に自動で反映されます。

## 主な機能

| 画面 | 内容 |
|---|---|
| 研修資料・テスト | 4月〜3月の研修資料、振り返りクイズ、確認テスト（自動採点・解説つき） |
| 研修実施記録 | 様式1 研修実施記録、様式2 参加者名簿・欠席者回覧確認表（点数・平均点・要フォロー者は自動集計） |
| 委員会・訓練 | 様式3 委員会議事録、様式4 訓練記録（BCP・感染症） |
| 新規採用時研修 | 様式5 新規採用時研修記録 |
| 運営指導対応 | 法定研修・委員会・訓練の実施状況チェック、記入漏れチェック、帳票の一括印刷、CSV出力 |
| 資料集 | Excelにあった研修資料（印刷可）・年間研修計画・参考資料リンク・白紙の様式1〜5・テスト問題用紙・解答 |
| 設定・バックアップ | バックアップの保存・復元、別端末のデータの取り込み |
| 説明書 | アプリの使い方（印刷・PDF保存可） |

## 運営指導で使える帳票

- 年間研修計画・実施状況
- 様式1・2（実施済の全研修を一括印刷。署名欄つき）
- 職員別 受講状況一覧（職員×12か月）／個人別 受講履歴
- 様式3・4（今年度の委員会議事録・訓練記録）
- 様式5（今年度採用者の新規採用時研修記録）
- 確認テスト問題用紙・解答解説
- 更新履歴（いつ何を記録したか）

印刷画面で「PDFに保存」を選ぶとPDFになります。署名欄は印刷後に手書きで署名をもらってください。

## データの保存について

- データはブラウザ（localStorage）に保存されます。サーバーには送信されません。
- 端末の故障やブラウザの履歴削除で消えるため、**月1回以上「バックアップを保存」**して、事業所のパソコンや共有フォルダに保管してください。
- 職員が各自のスマートフォンでテストを受けた場合は、その端末でバックアップを保存し、事務所の端末で「追加で取り込む」を選ぶと結果をまとめられます。

## インターネットで公開する場合（GitHub Pages）

リポジトリの Settings → Pages で、公開するブランチとフォルダ（`/ (root)`）を選ぶと、`https://<ユーザー名>.github.io/kaigokansyuu/` で開けるようになります。
公開しても記録データは各端末の中にだけ保存されます。

## 研修資料・テストの更新

研修資料とテストは `js/data.js` に入っています。Excel（研修計画・研修資料・記録様式／研修確認テスト集）を更新した場合は、次のコマンドで作り直せます。

```
python3 tools/extract.py 研修確認テスト集.xlsx 研修計画・研修資料・記録様式.xlsx js/data.js
```

解答Excel（`docs/確認テスト_解答一覧.xlsx`）は次のコマンドで作り直せます。

```
python3 tools/make_answers.py js/data.js docs/確認テスト_解答一覧.xlsx
```

解答用紙Excel（`docs/確認テスト_解答用紙.xlsx`）は `python3 tools/make_answer_sheets.py js/data.js docs/確認テスト_解答用紙.xlsx` で作り直せます。

（いずれも `pip install openpyxl` が必要です）
